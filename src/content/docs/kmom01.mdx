Den här veckan kommer du igång med web scraping i Node.js. Du lär dig att hämta HTML-sidor med `fetch`, ladda och traversera DOM:en med biblioteket cheerio, och plocka ut specifik information. Det är flödet du återanvänder i alla kommande uppgifter, så det lönar sig att förstå varje steg ordentligt.

## Issues

Arbeta igenom issues i ordning. Varje issue är ett steg framåt i applikationen.

Du är välkommen att skriva egna kommentarer i varje issue medan du arbetar — noteringar, frågor eller korta reflektioner om vad du lärde dig. Det hjälper dig att minnas och ger läraren inblick i din process. Stäng ett issue när du anser att det är klart.

| Issue | Namn           | Vad du gör                                                              |
| ----- | -------------- | ----------------------------------------------------------------------- |
| 01    | `fetchPage`    | Hämta startsidan med `fetch`, ladda i cheerio, skriv ut metadata        |
| 02    | `navLinks`     | Plocka ut alla navigeringslänkar ur `<nav>`, bygg array av objekt       |
| 03    | `openingHours` | Skrapa öppettidstabellen, filtrera stängda dagar, hitta senaste stängningstid |
