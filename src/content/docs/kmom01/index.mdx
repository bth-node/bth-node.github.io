Genomgången visar begreppen och hur de fungerar.

### Block 1 — fetch och async/await (60 min)

Visa hur `fetch` och Promises fungerar med minimala exempel. Poängen är att studenten förstår vad som händer under huven innan de skriver sin egen kod.

- Vad är ett Promise? Visa i Node REPL: `fetch("https://example.com")` — returnerar ett Promise, inte ett svar
- Visa `async/await` mot ett enkelt anrop: `const res = await fetch(...)` — vad händer utan `await`?
- Visa `response.ok` och `response.status` — öppna en sida som ger 404 och visa att koden inte kraschar men `ok` är `false`
- Visa `response.text()` kontra `response.json()` — samma kropp, olika parsning
- Visa cheerio på en hårdkodad HTML-sträng direkt i terminalen (ingen server behövs):
  ```js
  const $ = cheerio.load('<h1>Hej</h1><p class="tagline">Text</p>')
  $("h1").text()        // → "Hej"
  $(".tagline").text()  // → "Text"
  ```
- Visa skillnaden med och utan `.trim()` på en sträng med osynliga blanktecken

### Block 2 — Selektorer och iteration (50 min)

Visa hur man navigerar en riktig HTML-sida med cheerio. Starta servern och öppna källkoden i webbläsaren parallellt så studenter ser kopplingen mellan HTML-strukturen och selektorn.

- Starta `npm run site-1` — öppna DevTools → Inspect och visa tabell-strukturen
- Visa selektorer live: `$("nav a")`, `$("table#oppettider tbody tr")`, `$("td").eq(2)`
- Visa `for...of` vs `.each()` på samma element — välj ett och förklara varför.
- Visa strängjämförelse för klockslag: `"18:00" > "17:00"` i Node REPL — varför fungerar det?
- Visa vad som händer vid `"9:00" > "10:00"` — varför nollpaddat format är viktigt
- 5 min: vad kmom02 handlar om — data som behöver rensas och analyseras
