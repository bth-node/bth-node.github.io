Den här veckan kommer du igång med Node.js-backendutveckling. Du skapar din första Express-server, bygger ett REST API och sätter upp verktyg för kodkvalitet — linting, formattering, CI och automatiserade tester. Veckan lägger grunden för resten av kursen.

## Kom igång

:::danger
Kursrepot är ännu inte släppt. Du kan inte börja jobba med den här delen av kursen än.
:::

Ditt repo är förberett och finns på GitHub. Klona det till din dator:

```bash
git clone git@github.com:bth-node/backend-<studentakronym>.git
cd backend-<studentakronym>
```

Fortsätt sedan med README.md i repot för att installera beroenden och starta upp miljön.

Arbeta igenom issues i ordning. Varje issue är ett steg framåt i applikationen.

## Inlämning

1. Stäng de GitHub-issues som du har löst klart.
2. Skriv klart din redovisningstext i `report/kmom04.md`.
3. Kör `npm run lint` och `npm run format` så att koden är ren.
4. Committa, tagga och pusha:

```bash
git add .
git commit -m "kmom04 done"
git tag v4.0.0
git push origin main --tags
```

Behöver du uppdatera din inlämning efteråt? Committa ändringen och tagga om med en ökad patch-version, t.ex. `v4.0.1`.
