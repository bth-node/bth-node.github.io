Kursen Programmering med JavaScript och Node, a.k.a. node, lär ut teori och praktik för att hantera JavaScript på serversidan. Kursen är första delen i kurspaketet "Backend".

Vi utgår ifrån en färdig applikation där frontend och backend är separerade. Till vår hjälp får vi en färdig frontend och ett API som vi ska implementera steg för steg. Vi ska i slutändan ha en färdig webbapplikation där vi står för all backend.



Innehåll
------------------------

Kursen omfattar följande områden:

* Node.js (JavaScript på serversidan).

* MongoDB (NoSQL-databas).

* Docker (containerisering).

* Socket.io (realtidskommunikation).

* JSON Web Tokens (autentisering).

* Integrering av AI i backend.
